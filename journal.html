📸 Screenshot Trade Journal

Moves are fast — capture the chart, then review your exit. Entries are stored in the GitHub repo, so every device sees the same journal.

🔐 Private & encrypted: entries, trade fills, notes, P/L and screenshots are encrypted in your browser (AES-256-GCM, key from your passphrase via PBKDF2 · 310,000 iterations) before they're saved to the public repo MadHamster6000/DIYupload. Without the passphrase the files are unreadable. Your token and passphrase are kept only in this browser. If you forget the passphrase, the journal can't be recovered — keep it safe and export backups.

📋 Paste today's trade list

Paste Wealthsimple order history (copied text, Activity CSV export, or tab-separated). The parser finds ticker, strike, expiry, call/put, buy/sell, qty, price and time (ET), then tags each fill as entry / add / exit. Review and fix the preview, then save — one commit for the whole list.

Best: Wealthsimple → Activity → export CSV, then Load CSV file (or paste its text). Only ticker, strike, expiry, call/put, side, qty, price, commission and time are kept — account ID, account type, settlement date, description and name are dropped while parsing, and the pasted text is cleared right away.
