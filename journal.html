📋 Paste today's trade list

Paste Wealthsimple order history (copied text, Activity CSV export, or tab-separated). The parser finds ticker, strike, expiry, call/put, buy/sell, qty, price and time (ET), then tags each fill as entry / add / exit. Review and fix the preview, then save — one commit for the whole list.

Best: Wealthsimple → Activity → export CSV, then Load CSV file (or paste its text). Only ticker, strike, expiry, call/put, side, qty, price, commission and time are kept — account ID, account type, settlement date, description and name are dropped while parsing, and the pasted text is cleared right away.
